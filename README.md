# Sandbox

Мобильная 2D-песочница на Rust с физикой ragdoll на rapier2d.

## Реализовано

- игровой цикл на macroquad;
- главное меню, настройки и пауза;
- боковое меню спавна;
- вкладки пистолетов, оружия, мелонов и механизмов;
- спавн физических предметов;
- сенсорный виртуальный джойстик;
- управление ragdoll с клавиатуры и сенсорного экрана;
- перемещение мелона и спавнимых предметов пальцем;
- панорамирование камеры одним пальцем;
- приближение и отдаление камеры двумя пальцами;
- отдельные сенсорные зоны для оружия, гранаты и бочки;
- физический мир с гравитацией и суставами;
- персонажи Melon и Robot;
- карты Test Range, City и Laboratory;
- статичные препятствия;
- динамические ящики;
- разрушаемые бочки;
- пистолеты и оружие;
- физические снаряды;
- гранаты со взрывом;
- визуальные модели Melon, Robot, оружия и предметов;
- стержни, верёвки и пружины;
- поршень;
- кнопка с автоматической реакцией на приближение объекта;
- переключатель с клавиатурным и сенсорным управлением;
- автоматическая сборка debug APK через GitHub Actions.

## Управление

На компьютере:

- Enter или пробел открывают игру;
- C меняет персонажа;
- M меняет карту;
- A и D или стрелки управляют движением;
- W и S или стрелки применяют вертикальное воздействие;
- E переключает оружие;
- F или левая кнопка мыши использует оружие;
- G создаёт гранату;
- B создаёт бочку;
- Q создаёт ящик;
- R создаёт стержень;
- Y создаёт верёвку;
- L создаёт пружину;
- T создаёт поршень;
- U создаёт кнопку;
- I создаёт переключатель;
- O переключает все переключатели;
- P или Escape открывают паузу.

На Android:

- виртуальный джойстик управляет движением;
- красная кнопка использует выбранное оружие;
- нижняя правая зона переключает оружие;
- центральная нижняя зона создаёт гранату;
- правая нижняя зона создаёт бочку;
- касание объекта позволяет перетаскивать его;
- движение пальцем по свободной области перемещает камеру;
- движение двумя пальцами перемещает камеру и изменяет масштаб;
- боковая кнопка открывает меню спавна;
- вкладки меню переключают категории предметов;
- нажатие на предмет создаёт его в игровой сцене;
- касание переключателя меняет его состояние.

В меню спавна доступны категории Pistols, Weapons, Melons и Mechanisms.

## Сборка

Сборка Android запускается автоматически при push в main, создании тега с префиксом v или вручную через GitHub Actions.

Готовый APK публикуется в разделе Artifacts соответствующего запуска workflow.

Для локальной сборки необходимы Rust, Android SDK, Android NDK и цель aarch64-linux-android. Версия Android SDK соответствует API 34, минимальная версия Android — 23.
