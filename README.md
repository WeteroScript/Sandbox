# Sandbox

Мобильная 2D-песочница на Rust с физикой ragdoll на rapier2d.

## Реализовано

- игровой цикл на macroquad;
- главное меню, настройки и пауза;
- боковое меню спавна;
- вкладки пистолетов, оружия, мелонов и механизмов;
- спавн отдельных физических предметов;
- сенсорный виртуальный джойстик;
- управление ragdoll с клавиатуры и сенсорного экрана;
- перемещение частей мелона пальцем;
- панорамирование камеры одним пальцем по свободной области;
- приближение и отдаление камеры двумя пальцами;
- отдельные сенсорные зоны для оружия, гранаты, бочки и ящика;
- физический мир с гравитацией и суставами;
- персонажи Melon и Robot;
- различная масса, сила управления и прочность суставов персонажей;
- выбор персонажа и карты;
- карты Test Range, City и Laboratory;
- статичные препятствия;
- динамические ящики с прочностью;
- разрушаемые бочки;
- разрушение предметов от попаданий и взрывов;
- повреждение суставов и отрыв конечностей;
- индикатор целостности суставов;
- пистолет;
- бесшумный пистолет;
- тяжелый пистолет;
- винтовка;
- дробовик;
- бита;
- катана;
- отдельные физические модели оружия;
- физические снаряды с обнаружением попаданий;
- граната с таймером 3 секунды;
- радиальный импульс от взрыва;
- цепные взрывы бочек;
- визуальные эффекты взрыва;
- текстурированное отображение мелона;
- отдельное отображение робота;
- визуальные детали оружия, гранат, бочек, ящиков и платформ;
- автоматическая сборка debug APK через GitHub Actions.

## Управление

На компьютере:

- Enter, пробел или левая кнопка мыши открывают игру;
- C меняет персонажа в главном меню;
- M меняет карту в главном меню;
- A и D или стрелки управляют движением;
- W и S или стрелки применяют вертикальное воздействие;
- E переключает оружие;
- F или левая кнопка мыши использует оружие;
- G создает гранату;
- B создает бочку;
- Q создает ящик;
- X наносит тестовое повреждение суставам;
- P или Escape открывают паузу;
- Escape или Backspace возвращают в меню.

На Android:

- виртуальный джойстик управляет движением;
- красная кнопка использует выбранное оружие;
- нижняя правая зона переключает оружие;
- центральная нижняя зона создает гранату;
- правая нижняя зона создает бочку;
- синяя кнопка создает ящик;
- касание части мелона позволяет перетаскивать ее;
- движение пальцем по свободной области перемещает камеру;
- движение двумя пальцами перемещает камеру и изменяет масштаб;
- боковая кнопка открывает меню спавна;
- вкладки меню переключают категории предметов;
- нажатие на предмет создает его в игровой сцене.

В меню спавна доступны следующие категории:

- Pistols;
- Weapons;
- Melons;
- Mechanisms.

В меню паузы:

- Resume продолжает симуляцию;
- Spawn Box создает разрушаемый ящик;
- Spawn Grenade создает гранату с таймером 3 секунды;
- Spawn Barrel создает бочку;
- кнопки работают с клавиатуры и через сенсорный экран.

## Сборка

Сборка Android запускается автоматически при push в main, создании тега с префиксом v или вручную через GitHub Actions.

Готовый APK публикуется в разделе Artifacts соответствующего запуска workflow.

Для локальной сборки необходимы Rust, Android SDK, Android NDK и цель aarch64-linux-android. Версия Android SDK соответствует API 34, минимальная версия Android — 23.
