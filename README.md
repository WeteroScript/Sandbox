# Sandbox

Активная версия проекта переписывается на **C++20** в каталоге [CppProject](CppProject/README.md). SDL3 отвечает за окно, отрисовку и ввод, Box2D 3.2 — за физику предметов, персонажей и механизмов.

## Текущая C++-версия

- Карты Test Range, City и Laboratory с отдельной геометрией.
- Физические предметы: ящики, мячи, бочки и платформы.
- Персонажи Melon и Robot — отдельные шестисоставные ragdoll-сборки с суставами.
- Вода с плавучестью и сопротивлением; погружение считается по фактической площади пересечения окружностей и повёрнутых прямоугольников с жидкостью.
- Процедурные материалы предметов: объёмное освещение, фаски, древесная текстура, металлические панели, крепления, блики и контактные тени.
- Детализированные фоны карт: городские фасады с окнами, панели лаборатории и разметка испытательной площадки.
- Стержни, верёвки, пружины, поршни, кнопки и переключатели.
- Инструменты GRAB, FREEZE, CLONE и DELETE; операции с персонажами выполняются для всей группы.
- Каталог предметов и механизмов, размещение нескольких объектов за касание.
- Сенсорное управление, перетаскивание объектов, панорамирование и pinch-zoom камеры.
- Сохранение и загрузка сцены, включая карту, физические параметры, персонажей и механизмы.

## Android

Android-проект находится в `CppProject/android-project`. APK workflow запускается вручную через GitHub Actions. В этой ветке APK не собирается автоматически и не запускался в рамках текущих изменений.
