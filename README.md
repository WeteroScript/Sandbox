# Sandbox

Мобильная 2D-песочница на Rust с физикой ragdoll на rapier2d.

## Реализовано

- игровой цикл на macroquad;
- главное меню, настройки и пауза;
- сенсорный виртуальный джойстик;
- управление ragdoll с клавиатуры и сенсорного экрана;
- физический мир с гравитацией и суставами;
- персонажи Melon и Robot;
- различная масса, сила управления и прочность суставов персонажей;
- выбор персонажа и карты;
- карты Test Range, City и Laboratory;
- статичные препятствия для разных карт;
- динамические ящики;
- спавн ящиков через кнопку предметов;
- повреждение суставов от высокой относительной скорости частей тела;
- отрыв конечностей при разрушении суставов;
- индикатор целостности суставов;
- автоматическая сборка debug APK через GitHub Actions.

## Управление

На компьютере:

- Enter, пробел или левая кнопка мыши открывают игру;
- C меняет персонажа в главном меню;
- M меняет карту в главном меню;
- A и D или стрелки управляют движением;
- W и S или стрелки применяют вертикальное воздействие;
- Q создаёт динамический ящик;
- X наносит тестовое повреждение суставам;
- P или Escape открывают паузу;
- Escape или Backspace возвращают в меню.

На Android:

- виртуальный джойстик управляет направлением движения;
- кнопка A предназначена для действий;
- кнопка с плюсом создаёт ящик.

## Сборка

Сборка Android запускается автоматически при push в main, создании тега с префиксом v или вручную через GitHub Actions.

Готовый APK публикуется в разделе Artifacts соответствующего запуска workflow.

Следующим этапом будут добавлены оружие, гранаты, взрывы, бочки и разрушаемые предметы.
