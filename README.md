# Sandbox

Мобильная 2D-песочница на Rust с физикой ragdoll на rapier2d.

## Реализовано

- игровой цикл на macroquad;
- главное меню;
- экран настроек;
- экран паузы;
- базовый сенсорный интерфейс;
- физический мир с гравитацией;
- статичная платформа;
- динамический ящик;
- ragdoll из головы, торса и конечностей;
- суставные соединения между частями тела;
- автоматическая сборка debug APK через GitHub Actions.

## Сборка

Сборка Android запускается автоматически при push в main, создании тега с префиксом v или вручную через GitHub Actions.

Готовый APK публикуется в разделе Artifacts соответствующего запуска workflow.

## Управление прототипом

На компьютере:

- Enter, пробел или левая кнопка мыши открывают игру;
- S, Tab или правая кнопка мыши открывают настройки;
- P или Escape открывают паузу;
- Escape или Backspace возвращают в меню.

На Android слой сенсорного интерфейса уже отображается на игровом экране.

Следующим этапом будут добавлены управление ragdoll, интерактивные предметы, персонажи и карты.
